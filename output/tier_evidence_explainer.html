human-mouse variant correspondenceを作る2つのCategory

Categoryは信頼度の順位ではなく、異なる証拠の結び方です。Category 1はHPO–MP ontology bridge、Category 2はortholog内で得る表現型名または疾患モデルの根拠であり、それぞれの由来をsub-categoryとして保存します。

ゲノム上のmatching pointから、根拠別のリストを作る

各Categoryが保存するもの

Category 1-1

1,089,740 rows

MHMI high-confidence HPO-MP bridge

  • ClinVar condition → HPO
  • MHMI HPO-MP confidence ≥0.8
  • MGI allele/genotype
  • predicate、confidence、sourceを保持

Category 1-2

986,121 rows

Monarch UPheno bridge

  • ClinVar condition → HPO
  • Monarch crossSpeciesExactMatch
  • 数値confidenceなし
  • 1-1と別に出典を保持

Category 2

76,619 / 331,245 rows

Ortholog-first evidence

  • 2-1: phenotype label
  • 2-2: curated disease model
  • shared OMIM ID
  • variant equivalenceは主張しない

DBではpairと接続根拠を分離する

variant_pair

  • human gene + rsID
  • mouse gene + MGI allele/genotype
  • ortholog pair ID
1 → n

category_evidence

  • pair ID + category/subcategory ID
  • human/mouse phenotype
  • ontology predicate / shared OMIM / match method
  • source record + review status

Category番号をconfidence scoreとして比較しません。各Categoryの元データ、適用範囲、review条件を保ったまま検索します。Semantic class A/B/C/DはCategory 2-1のB/Cとは別分類です。

Category説明図はデータ構造と接続根拠を示します。TLR4・CFTR・ALPLのケーススタディは、別HTMLでこの設計が実際の対象ペア回収にどう効くかを示します。
