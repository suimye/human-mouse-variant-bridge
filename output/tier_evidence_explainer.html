human-mouse variant correspondenceを作る3つのTier

3つのTierは信頼度の順位ではなく、異なる証拠の結び方です。共通するのは、human Gene Aとmouse Gene Aの1:1 orthologを先に確定し、その遺伝子内のvariant、allele、phenotype evidenceを接続することです。

ゲノム上のmatching pointから、根拠別のリストを作る

各Tierが保存するもの

Tier 1

1,089,740 rows

Ontology phenotype bridge

  • ClinVar condition → HPO
  • HPO-MP mapping
  • MGI allele/genotype
  • predicate、confidence、sourceを保持

Tier 2

76,619 rows

Ortholog-first phenotype evidence

  • ClinVar/GWAS phenotype
  • MGI MP/allele name
  • B: 小文字化・記号除去・定義済み別名置換後に全文一致
  • C: 語彙一致の仮説候補、要レビュー

Tier 3

331,245 rows

Curated disease model

  • ClinVar condition identifier
  • MGI curated disease model
  • shared OMIM ID
  • variant equivalenceは主張しない

DBではpairと接続根拠を分離する

variant_pair

  • human gene + rsID
  • mouse gene + MGI allele/genotype
  • ortholog pair ID
1 → n

tier_evidence

  • pair ID + tier ID
  • human/mouse phenotype
  • ontology predicate / shared OMIM / match method
  • source record + review status

Tier番号をconfidence scoreとして比較しません。各Tierの元データ、適用範囲、review条件を保ったまま検索します。Semantic class A/B/C/DはTier 2のB/Cとは別分類です。

Tier説明図はデータ構造と接続根拠を示します。TLR4・CFTR・ALPLのケーススタディは、別HTMLでこの設計が実際の対象ペア回収にどう効くかを示します。
