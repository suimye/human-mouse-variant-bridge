# Retired manual human phenotype input

`human_variant_phenotypes.retired.tsv` is retained only as an audit record of the former TLR4-specific manual input. The 2026 pipeline does not read this file. Manual literature-derived human phenotype rows are not added to Tier 2 or the semantic correspondence database.

TLR4 is retained as a semantic class C candidate using the already downloaded GWAS Catalog evidence and MGI evidence. The retired sentence must not be used to raise TLR4 to semantic class A or Tier 2 support A.
